cowtree
brew install paakofiaidoo/tap/cowtree

A separate workspace for every AI agent, at no disk cost

Every Claude Code, Codex or Cursor agent gets its own instant copy of your project. Under the hood: copy-on-write git worktrees.

$ cowtree ls ~/code/myapp
~/code/myapp  (base)
~/code/wt/myapp-fix-login  [fix-login]  logical 301.0MB  owned 8.0KB  base ~/code/myapp
~/code/wt/myapp-payments-retry  [payments-retry]  logical 301.0MB  owned 12.0KB  base ~/code/myapp
~/code/wt/myapp-search-index  [search-index]  logical 301.0MB  owned 8.0KB  base ~/code/myapp
