How it works: clonefile, not copies

Black squares are the base. Outlined squares are clones that share its blocks and cost 0 bytes. Red is an edited block, green a new file.

  1. git worktree add --no-checkout creates the branch and metadata.
  2. cp -c -R clones every top-level entry except .git, ignored dirs included.
  3. git read-tree fills the index without rewriting the clones.
  4. No FUSE, no daemon. Editors and compilers see ordinary files.
